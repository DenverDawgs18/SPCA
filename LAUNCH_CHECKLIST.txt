1. MERGE & DEPLOY
-----------------
Merge the feature branch into main and push to Fly.io.

  git checkout main
  git merge claude/relaxed-mendel-e3cY6
  git push origin main
  fly deploy

That's one deploy. Migrations run automatically as part of fly deploy
(the release_command in fly.toml handles it).


2. SET EMAIL SECRETS ON FLY
----------------------------
Email is only needed for automatic notifications: application received,
approved, and denied. Group emails to volunteers do NOT need this — managers
compose them in the portal and send from their own Gmail.

Pick one option for the automatic notifications:

Option A — SendGrid (recommended, free up to 100 emails/day)
  Sign up at sendgrid.com, create an API key with "Mail Send" permission, then:

  fly secrets set EMAIL_BACKEND="django.core.mail.backends.smtp.EmailBackend"
  fly secrets set EMAIL_HOST="smtp.sendgrid.net"
  fly secrets set EMAIL_PORT="587"
  fly secrets set EMAIL_USE_TLS="True"
  fly secrets set EMAIL_HOST_USER="apikey"
  fly secrets set EMAIL_HOST_PASSWORD="SG.your-api-key-here"
  fly secrets set DEFAULT_FROM_EMAIL="Medina County SPCA <noreply@medinacountyspca.com>"

Option B — Gmail App Password
  Go to myaccount.google.com/apppasswords, create an App Password, then:

  fly secrets set EMAIL_BACKEND="django.core.mail.backends.smtp.EmailBackend"
  fly secrets set EMAIL_HOST="smtp.gmail.com"
  fly secrets set EMAIL_PORT="587"
  fly secrets set EMAIL_USE_TLS="True"
  fly secrets set EMAIL_HOST_USER="theiraddress@gmail.com"
  fly secrets set EMAIL_HOST_PASSWORD="xxxx xxxx xxxx xxxx"
  fly secrets set DEFAULT_FROM_EMAIL="Medina County SPCA <theiraddress@gmail.com>"

Skip this step if you want to test everything first and add email later.
Without it the site works fine — auto-notifications just won't go out.


3. CREATE THE FIRST MANAGER ACCOUNT
-------------------------------------
This person will log in to the volunteer portal as a manager.

  fly ssh console -C "python manage.py createsuperuser"

Enter a username, email, and password when prompted. This account gets
access to both /portal/manager/ AND /admin/.

If an admin account already exists from before, you can reuse it —
is_superuser implies is_staff, so it already has manager access.
Or create a separate staff-only account:

  fly ssh console
  # then inside the shell:
  python manage.py shell -c "
  from django.contrib.auth.models import User
  u = User.objects.create_user('manager', 'their@email.com', 'choose-a-password')
  u.is_staff = True
  u.first_name = 'Their'
  u.last_name = 'Name'
  u.save()
  "


4. LOAD SAMPLE ANIMALS (if not already done)
---------------------------------------------
  fly ssh console -C "python manage.py loaddata sample_pets"

Puts 5 placeholder animals on the site so the Adopt page isn't empty.
Replace them with real animals via /admin/ → Animals.


5. CUSTOM DOMAIN (if using medinacountyspca.com)
-------------------------------------------------
  fly certs add medinacountyspca.com
  fly certs add www.medinacountyspca.com

  fly secrets set \
    ALLOWED_HOSTS="medina-county-spca.fly.dev,medinacountyspca.com,www.medinacountyspca.com" \
    CSRF_TRUSTED_ORIGINS="https://medina-county-spca.fly.dev,https://medinacountyspca.com,https://www.medinacountyspca.com"

Then update the DNS at your registrar:
  CNAME  www   →  medina-county-spca.fly.dev
  A/ALIAS @    →  (IP shown by `fly ips list`)

fly certs check medinacountyspca.com   ← confirms SSL is provisioned


6. DROP IN THE REAL LOGO
